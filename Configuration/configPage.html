Intro/Credits Backup & Restore

Backs up and restores intro/credits chapter markers as one JSON and/or NFO file per episode. Run the "Backup Intro/Credits Markers" and "Restore Intro/Credits Markers" tasks from Scheduled Tasks.

Backup & Restore Options

Backup:

Folder where per-episode JSON backups are stored, flat (no per-series subfolders).
Folder where per-episode standalone NFO backups are stored, flat (no per-series subfolders). This is a plugin-owned file containing only a <markers> element - unrelated to Emby's own scraper-generated NFO next to the video.
Note: if both JSON and NFO are checked, the Backup task writes fresh data to both on every run. If both are checked for Restore below, the plugin uses whichever source has a value for each field (Intro/Credits handled independently), preferring the more recently written file when both sources have a value for the same field.

Restore:

For both JSON and NFO manual-edit auto-backup: if enabled below, the plugin watches the Emby server log for signs of a manual marker correction made through ChapterApi, EmbyCredits, or Segment Reporting - none of these raise the update event "Automatically restore" below listens for, so without that setting, a manual correction is never backed up.

Backup:

If enabled, each episode's backup is written next to its video file, either as JSON or NFO.

On backup, adds a <markers> element (with the same schema the original commercial "Intros Backup/Restore" plugin used) directly into the NFO file Emby's own metadata scraper already writes next to each video - only if that file already exists; nothing is created from scratch. Everything else already in that NFO is preserved. On restore, this same <markers> element is also read as a fallback if no JSON backup is found for an episode - so existing backups made by the original commercial plugin can be restored directly, with no conversion step needed.
Independent of the two options above - a "just in case" extra copy in a folder of your choosing, on top of whatever's being written next to your videos. Restore never reads from this copy; it exists purely as insurance.

Restore:

Uses whichever source (NFO or JSON) has a value for each field (Intro/Credits handled independently), preferring the more recently written file when both sources have a value for the same field.
Note: in Automatic mode, the scheduled Backup/Restore tasks use media folders.
