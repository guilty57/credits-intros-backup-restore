Intro/Credits Backup & Restore

Backs up and restores intro/credits chapter markers as one JSON file per episode. Run the "Backup Intro/Credits Markers" and "Restore Intro/Credits Markers" tasks from Scheduled Tasks.

Folder where per-episode JSON (and optional NFO) backups are stored. Files are written flat here - no per-series subfolders.
If enabled, a matching .nfo file is written next to each JSON backup.
