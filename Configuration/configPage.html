Intro/Credits Backup & Restore

Backs up and restores intro/credits chapter markers as one JSON file per episode. Run the "Backup Intro/Credits Markers" and "Restore Intro/Credits Markers" tasks from Scheduled Tasks.

Folder where per-episode JSON backups are stored, flat (no per-series subfolders). Ignored if "Save JSON backup files to media folders" below is checked.
If enabled, each episode's JSON backup is written next to its video file instead of the JSON backup path above.

Media NFO integration

On backup, adds a <markers> element (with the same schema the original commercial "Intros Backup/Restore" plugin used) directly into the NFO file Emby's own metadata scraper already writes next to each video - only if that file already exists; nothing is created from scratch. Everything else already in that NFO is preserved. On restore, this same <markers> element is also read as a fallback if no JSON backup is found for an episode - so existing backups made by the original commercial plugin can be restored directly, with no conversion step needed.

Auto-restore (experimental)

If enabled, the plugin watches for episode updates and immediately re-applies backed-up intro/credits markers whenever they're missing - whether that's from a Library Scan or a Refresh Metadata (both can wipe them; "Lock this item" only protects against Library Scan, not Refresh Metadata). Runs automatically in the background - no need to run the Restore task manually after library maintenance. Requires a JSON backup path (or media-NFO integration) to already be configured above. This is newer and less tested than the scheduled Restore task, so it's off by default.

Auto-backup on manual edit (experimental)

If enabled, the plugin watches the Emby server log for signs of a manual marker correction made through ChapterApi, EmbyCredits, or Segment Reporting - none of these raise the update event "Automatically restore" above listens for, so without this, a manual correction is never backed up. Also reacts to Emby's own native intro detection, which only knows about Intro markers: when it runs, this backs up the new intro and reapplies any existing credits marker so it isn't lost. Independent of "Automatically restore" above - either can be used without the other. Off by default.
